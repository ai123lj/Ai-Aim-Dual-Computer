# gprs - 采集卡2.2

## 项目概述
这是一个基于C#开发的图像采集与自动控制应用程序，主要用于通过美乐威(Magewell)采集卡捕获图像，结合YOLO人体姿态识别算法，实现目标自动检测和控制指令发送。该项目集成了多源图像采集、实时目标检测和串口控制等功能，可应用于多种自动化视觉控制场景。仅供学习使用。

## 主要功能

### 🎯 多源图像采集
- **美乐威采集卡**：支持Pro系列采集卡，通过SDK实现高质量图像捕获
- **网络流采集**：预留了TCP网络流接收功能，可从远程设备获取图像
- **本地屏幕采集**：支持截取本地屏幕特定区域的图像

### 👁️ 智能目标检测
- 集成**YOLOv8**姿态识别模型，可精准检测人体关键点
- 支持多种目标瞄准点选择：额头、胸部、鼻子等
- 采用零拷贝图像处理技术，提高检测效率

### 🎮 自动控制机制
- 支持三种射击模式：狙击(Sniper)、点射(Burst)、自动(Auto)
- 通过串口发送鼠标控制指令，实现精确瞄准和射击
- 可自定义射击参数，适应不同场景需求

### 📊 辅助功能
- 性能测试：内置鼠标执行速度测试
- 反应测试：检测视觉变化并快速响应
- 可视化监控：实时显示采集和处理的图像

## 技术架构

### 核心组件
1. **图像采集模块**：基于MWCapture SDK封装，支持多种采集设备
2. **图像处理模块**：集成YOLO算法，实现人体检测和姿态识别
3. **控制指令模块**：通过串口通信发送控制命令
4. **用户界面模块**：Windows Forms界面，提供配置和监控功能

### 数据流
采集卡 → 图像捕获 → 图像预处理 → YOLO检测 → 目标定位 → 控制指令生成 → 串口发送

## 系统要求

### 硬件要求
- Windows操作系统（推荐Windows 10/11）
- 支持美乐威采集卡（Pro系列）
- 具备USB串口通信能力的设备
- 推荐配置：4核CPU、8GB内存、独立显卡（用于YOLO推理加速）

### 软件要求
- .NET Framework 4.7.2或更高版本
- Visual Studio 2019或更高版本（开发环境）
- 美乐威MWCapture SDK
- YOLOv8模型文件（yolov8m-pose.onnx）

## 安装与配置

### 1. 环境准备
- 安装Visual Studio并配置.NET开发环境
- 安装美乐威采集卡驱动和SDK
- 准备YOLOv8模型文件

### 2. 项目编译
- 使用Visual Studio打开`gprs.sln`解决方案
- 还原NuGet包依赖
- 编译整个解决方案

### 3. 配置设置
- 确保YOLO模型文件`yolov8m-pose.onnx`位于应用程序目录
- 配置串口参数（波特率：2000000，数据位：8，停止位：1，无校验）
- 根据需要调整图像采集参数（默认分辨率：640x640）

## 使用说明

### 启动应用
- 运行编译后的可执行文件
- 应用程序会自动初始化采集卡并开始图像捕获

### 主要操作
- **模式选择**：选择不同的射击模式（狙击/点射/自动）
- **参数调整**：根据需要调整瞄准点和灵敏度
- **监控显示**：通过界面实时查看处理后的图像

### 快捷键与控制
- `Ctrl`键：在反应测试模式下设置基准颜色
- 界面控件：调整各项参数和模式选择

## 注意事项

1. **模型文件**：确保正确放置YOLOv8模型文件，否则无法进行目标检测
2. **串口连接**：使用前请确保串口设备正确连接并配置
3. **性能优化**：对于低配置设备，可能需要降低图像分辨率以提高性能
4. **资源释放**：程序关闭时会自动释放资源，但异常关闭可能导致资源泄漏
5. **驱动兼容性**：请使用与采集卡型号匹配的最新驱动程序

## 故障排除

- **无法检测到采集卡**：检查驱动安装和硬件连接
- **串口通信失败**：确认串口参数设置和物理连接
- **检测性能低下**：考虑降低分辨率或使用GPU加速
- **程序崩溃**：检查是否正确放置了YOLO模型文件
